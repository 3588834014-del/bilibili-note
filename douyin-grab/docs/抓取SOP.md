# 抖音图文抓取 · 标准操作流程（写给 Codex / Claudian）

> 当用户说「**抓这条：\<分享口令>**」时，你（Codex）按以下步骤执行。本文件是流程唯一权威依据，不要自行打标签。

---

## 0. 前置

- 只处理**图文**内容。视频/直播不归本管线管。
- 你只负责「读图、总结、写笔记」；**去标签、解析、下载图片**都是脚本 `dy_grab.py` 干的确定性活儿。
- 全程**不要**给笔记填 `tags`——分类交给既有归档管线（Templater + Auto Note Mover + Dataview）。

---

## 1. 运行抓取脚本

```bash
python <skill-dir>/scripts/dy_grab.py --vault "<Obsidian 库根>" "<分享口令>"
```

读取 stdout 最后一行 JSON。根据 `status` 决定下一步。

---

## 2. 结果分流

### 情况 A：`status == "duplicate"`

说明之前抓过了。直接告诉用户：
> 这条之前已经抓过了，笔记在：`<note 字段给出的标题>`
结束，不做任何写入。

### 情况 B：`status == "ok"`

拿到 `aweme_id`、`meta_path`。继续第 3 步。

### 情况 C：退出码非 0（status 不是 ok/duplicate）

用一句人话解释并把原因转达用户，**不要**硬凑笔记：

| 退出码 | 含义 | 转达人话示例 |
| --- | --- | --- |
| `2` | 口令没链接 | 「这条口令里好像没找到链接，请重新复制完整的分享口令」 |
| `3` | 解析失败 | 「抖音解析失败了，可能是链接失效或触发了风控，建议配置 cookie 再试」 |
| `4` | 网络错误 | 「网络连不上，请检查网络后重试」 |
| `5` | 非图文 | 「这条是视频/直播，本管线只支持图文」 |
| `6` | 未找到库根 | 「没定位到 Obsidian 库，请把库根路径传给我（--vault）」 |

---

## 3. 打开 meta.json，逐张看图

路径：`attachments/douyin/<aweme_id>/meta.json`，图片在同目录。

用你的视觉能力**逐张**查看图片，为每张写 **1–3 句客观描述**：
- 只描述**实实在在看到的东西**（主体、场景、构图、文字内容）。
- 不脑补、不夸张、不编故事。
- 图片可能带文字/弹窗/水印，如实描述即可。

---

## 4. 按模板写笔记到 Inbox

文件名 = 标题清洗后 ≤ 30 字 + 日期后缀（`YYYY-MM-DD`）。

```markdown
---
title: "（视频标题）"
source: "（原文链接）"
author: "（作者昵称）"
date: YYYY-MM-DD
type: douyin-图文
status: inbox
tags: []
---

## 文案

（caption 原文）

## 图片内容

![](（图片相对本笔记的路径，逐张嵌入）)

- 图1：（描述）
- 图2：（描述）

> 抓取于 YYYY-MM-DD HH:MM
```

**要点**：
- `tags: []` 必须空数组，**不要填**。
- 图片用 Obsidian 嵌入语法 `![](...)`，路径写成相对本笔记的；也可以直接嵌 `<image>`。
- 描述写进要点列表，与图片一一对应。

---

## 5. 收尾

回复用户笔记在 vault 中的位置（用 Obsidian 可打开的链接）。若期间有任何失败，用人话说明原因 + 下一步建议（例如重试、配置 cookie、换一条）。

---

## 6. 入档与分类（交给知识处理流程，你只管写对字段）

笔记写进 `00_Inbox` 后，**不要**由你（Codex）给它打标签或移动文件。
分类交给既有知识处理流程（见 `00_Inbox/_Inbox说明.md` 与 `20_知识处理/00_处理流程说明.md`）：

1. 先按内容类型判断所属领域：AI / 编程 / 学业 / IP项目 / 生活 / 人文 / 认知 / 商业 …（参考 `50_领域分类` 和 `_tags.md`）。
2. **技术/概念类**（AI、编程、数学、经济学等）→ 提取关键概念 → 用概念卡片模板建卡片 → 与已有笔记双链 → 归入对应领域 MOC。
3. **情感/散文/随笔** → 归入「生活 / 人文」领域，以原文笔记沉淀即可，不强拆概念。

你只需要保证 frontmatter 里 `type`、`status: inbox`、`tags: []`（空数组）正确，剩下的交给流程。
